# AlphaAI

A REST API and agent-native platform for relevance-scored, ticker-linked financial news, built for trading bots, agent backends, and dashboards. Articles are enriched at ingest with relevance scores, categories, and per-ticker sentiment, plus structured SEC Form 4 insider data.

- **Provider:** https://alphai.io

## APIs

- **AlphaAI REST API** — REST API for relevance-scored, ticker-linked financial news with nine stable endpoints covering news feeds, trending, insider (SEC Form 4) data, symbols, and sentiment/insider rollups. API key bearer token auth. (`https://api.alphai.io`)
- **AlphaAI MCP Server** — Hosted MCP server exposing 11 tools for news search, ticker news, trending, actionable-now, insider news, pair analysis, article retrieval, tickers, and alert management. OAuth 2.1 with RFC 7591 dynamic client registration over Streamable HTTP. (`https://mcp.alphai.io/mcp`)
- **AlphaAI Claude Code Skills** — Open-source pack of Claude Code agent skills wrapping the MCP tools into ready-made workflows: one-ticker brief, market pulse, insider-activity scan, two-ticker read-across, and alert management. (`https://github.com/makeev/alphai-claude-skills`)
